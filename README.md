# StatementCSV

Convert bank statement PDFs to CSV entirely in the browser. No server, nothing uploaded.

- `index.html` – the page
- `app.js` – UI, paywall and unlock logic
- `parser.js` – transaction extraction from pdf.js text content
- `vendor/` – pdf.js 4.10.38 (Apache-2.0)
- `config.js` – Stripe Payment Link URL and the SHA-256 of the unlock key

Hosted on GitHub Pages.
